# 心动星球 · 恋爱交友网站

单文件零依赖的恋爱交友平台演示，使用原生 HTML/CSS/JS，数据存储于浏览器 `localStorage`。

## 功能

- 💘 邮箱注册 / 登录（密码哈希，本地演示用，请勿填写真实隐私）
- 🔥 卡片式滑动匹配（拖拽手势 + 喜欢 / 略过 / 超级喜欢按钮 + 键盘 ←/→/↑ 快捷键）
- 🎯 发现页筛选器（性别 / 年龄段 / 城市 / 只看在线）
- 💞 双向喜欢即配对成功，机器人按概率回赞，配对后主动开场白
- 💬 站内聊天（匹配对象模拟回复 + 快捷短语 + 5 分钟内双击撤回消息）
- ✨ 动态广场（发动态 / 点赞 / 评论，机器人会点赞评论互动）
- ❤️ 心动消息（喜欢我的人一键回赞 + 谁看过我访客记录，访客可置顶到发现页）
- 👤 个人资料编辑（头像、昵称、性别、年龄、城市、自我介绍、兴趣标签）+ 资料完善度进度条
- 🌙 深色模式（跟随系统 / 手动切换）
- 🧹 略过持久化（左滑不再重复出现，可一键"找回略过的人"）+ 清空本地数据
- 📱 响应式移动适配 + PWA（可安装到主屏、离线壳，`sw.js` 页面网络优先防更新滞后）
- ✅ 功能探针：`node tests/probe.js`（无头 Chrome + CDP，21 项断言）

## 本地运行

直接双击打开 `index.html` 即可，无需构建。

## 部署到 Cloudflare Pages

1. 将本目录上传到 GitHub 仓库（或直接拖拽部署）
2. 在 Cloudflare Pages 新建项目，选择该仓库
3. 构建命令留空，输出目录留空（静态站点，`index.html` 即入口）
4. 部署完成后即可通过 `*.pages.dev` 访问

## 文件结构

```
heartverse-web/
├── index.html           # 主应用（单文件，全部逻辑）
├── sw.js                # Service Worker（离线壳，页面网络优先）
├── manifest.webmanifest # PWA 清单
├── icon.svg             # 矢量图标
├── icon-192.png         # 192×192 图标
└── icon-512.png         # 512×512 图标
```

## 说明

- 数据仅存本地，刷新不丢（localStorage），清除浏览器数据会重置
- 12 位虚拟用户（机器人）用于演示匹配与聊天
- 如需真实后端，可在 `functions/` 下用 Cloudflare Pages Functions 对接 D1 数据库
